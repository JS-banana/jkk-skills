# Dream

像大脑在睡眠中巩固记忆一样：回顾近期所有项目的对话，把值得留下的经验
写成持久记忆，把过时和重复的清掉。**报告先行——用户确认前不改任何文件。**

## 硬性规则

1. 在用户明确确认报告之前，不写入、不修改、不删除任何 memory 文件。
2. 只操作 `~/.claude/projects/<project>/memory/` 目录，不碰 transcripts 和其他文件。
3. 保持各项目既有的 memory 格式；每个 MEMORY.md 索引不超过 200 行。
4. 每条删除/合并操作必须在报告中逐条列出理由，不做静默清理。
5. **记忆按项目隔离**：A 项目会话中的信号只能写入 A 项目自己的 memory，
   严禁跨项目搬运或提炼「通用经验」写到别的项目——公司项目与个人项目
   可能同在一台机器上，知识归属不得混淆。

## 范围选择

默认扫描**全部**近期活跃项目（记忆隔离保证了这样做没有污染风险）。
用户话语中带范围时按其意图收窄：

- 「整理当前项目」→ 只处理当前工作目录对应的项目
- 「只整理 X」「整理 X 和 Y」→ 只处理点名的项目
- 「排除 X」「不要动公司项目」→ 从默认名单中剔除匹配项
- 「最近一个月」→ 换算 `--days`，范围仍按上述规则

## Phase 1 — Orient（定向）

运行本 skill 目录下的采集脚本，了解全局：

```bash
python3 scripts/gather.py --list --days 7
```

输出按活跃度排序：memory 文件数、近 N 天会话数、最后活跃日期。
用户如果说了时间范围（如「整理最近一个月」），换算成 `--days`。

选择处理对象：

- **默认处理**：近 N 天有会话记录的项目（`recent > 0`）。
- **候选新建**：有近期会话但无 memory 目录的项目——列入报告，确认后才创建。
- **跳过**：无近期活动的项目，在报告末尾列出名单即可；用户点名时再处理。

## Phase 2 — Gather Signal（采集信号）

对每个选中的项目，先读它的记忆，再读它的对话：

1. 读 `~/.claude/projects/<project>/memory/MEMORY.md` 和全部条目文件。
2. 提取近期会话中的真实用户输入（已过滤命令回显和工具结果）：

```bash
python3 scripts/gather.py --extract=<project-dir> --days 7
```

注意项目目录名以 `-` 开头，`--extract` 后必须用 `=` 连接。

在用户输入中寻找这些信号：

- **纠正**：用户否定或修正了 Claude 的做法（「不对」「不是这样」「改成…」）
- **偏好**：反复出现的工作方式、工具选择、表达习惯
- **决策**：被明确拍板的方案、约定、边界（「就这样」「可以提交」「以后都…」）
- **过时**：与现有 memory 条目矛盾的新事实、已完成的「进行中」事项、失效的相对日期

## Phase 3 — Consolidate（起草报告）

汇总成一份整理报告，按项目分节，每条操作附证据（来自哪次会话的什么话）：

```markdown
## <项目名>
### 拟新增
- `<slug>.md`（type: feedback）—— <一句话内容>。依据：<日期> 会话中「<原话摘录>」
### 拟更新
- `<slug>.md`：<改什么、为什么>
### 拟合并
- `<a>.md` + `<b>.md` → `<c>.md`：<重复点>
### 拟删除
- `<slug>.md`：<过时/矛盾的理由>

## 候选新建 memory 的项目
- <项目名>：<值得沉淀的内容概要>

## 本次跳过
- <项目名>（无近期活动）…
```

没有变化的项目写一行「无需调整」。把报告完整展示给用户，等待确认。
用户可以整体确认、部分确认（点名哪些条目执行）或要求修改。

## Phase 4 — Prune & Index（写入与重建索引）

仅对用户确认的操作：

1. 按报告执行新增/更新/合并/删除。条目文件保持既有 frontmatter 格式
   （`name` / `description` / `metadata.type: user|feedback|project|reference`），
   正文中相对日期一律转成绝对日期，相关条目用 `[[name]]` 互链。
2. 重建每个改动项目的 `MEMORY.md`：一行一条
   `- [标题](文件.md) —— 钩子句`，只放索引不放正文，≤ 200 行。
3. 汇报结果：每个项目新增/更新/合并/删除的条数，以及跳过的项目数。
